## The line

> I drop snacks for strangers all day, but you're the first one I've ever wanted to fall for.

One line, 91 characters, spoken by the machine itself: it drops snacks for
strangers all day, and the punch lands on the last words — it finally wants
to *fall* for someone.

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (deterministic — identical output on
every run).
